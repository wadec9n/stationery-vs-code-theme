# Stationery

> [!NOTE]
> This theme is a work in progress. Please file an Issue for any problems you encounter.

Stationery is a VS Code theme for people who take notes on paper. It comes in dark and light variants.

## The themes

### Stationery Light

A clean white editor with the surrounding chrome — sidebar, tabs, panels, status bar — shifted a half-step warmer into soft parchment. Text is nearly black. Syntax falls into:

- Deep terracotta for keywords and control flow.
- Forest green for strings (including JSX/Astro attribute values).
- Muted blue for types, classes, and HTML tags.
- A slightly brighter blue-teal for functions and methods.
- Warm ochre for properties, JSX attributes, and JSON keys.
- Rust for numbers, booleans, and regex.

### Stationery Dark

A near-black editor with charcoal chrome and warm cream text. The accents lift to hold weight against the dark field:

- Bright apricot for keywords and control flow.
- Soft mint for strings (including JSX/Astro attribute values).
- Pale cyan-blue for types, classes, and HTML tags.
- A brighter sky blue for functions and methods.
- Warm gold for properties, JSX attributes, and JSON keys.
- Desaturated terracotta-rust for numbers, booleans, and regex.

## Development Process

This theme was developed following [the excellent guidance that Sarah Drasner provided](https://css-tricks.com/creating-a-vs-code-theme/) while developing the [Night Owl theme](https://github.com/sdras/night-owl-vscode-theme). Night Owl has long been my theme of choice.

Claude and Codex were used heavily to create this theme. Building it was partly an exercise in shipping a usable project through agent and skill workflows that made iteration quick.
